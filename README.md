# The Mentalist Web 🕵️‍♂️🔴

Projeto desenvolvido como prática de desenvolvimento web, inspirado na série **The Mentalist**.

O site apresenta informações sobre a série, personagens e elementos inspirados nas investigações do CBI.

## ✨ Funcionalidades

* Página inicial temática
* Página sobre a série
* Página de contato inspirada em denúncias ao CBI
* Design inspirado no universo de *The Mentalist*


## 🛠️ Tecnologias utilizadas

* HTML
* CSS
* JavaScript
* Node.js
* Express

## 🚀 Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/ellenmariane/the-mentalist-web.git
```

Entre na pasta:

```bash
cd the-mentalist-web
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor:

```bash
node app.js
```

Ou com Nodemon:

```bash
npx nodemon app.js
```

Depois acesse no navegador:

```text
http://localhost:3000
```

## 📌 Sobre o projeto

Este é um projeto de estudo criado para praticar desenvolvimento web e trabalhar conceitos de estruturação de páginas, estilização, rotas com Node.js e organização de projetos com Git e GitHub.

O projeto continuará recebendo melhorias conforme meus estudos avançarem. 🚀



Este é um projeto não oficial feito apenas para fins educacionais e de estudo.
*The Mentalist* e seus personagens pertencem aos seus respectivos detentores de direitos.
